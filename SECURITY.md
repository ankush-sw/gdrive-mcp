# Security

Report a vulnerability privately. Do not open a public issue or PR with exploit details.

**Preferred:** [GitHub private vulnerability reporting](https://github.com/ankush-sw/gdrive-mcp/security/advisories/new) on this repo.

What the process accesses, and how to audit the code: [TRUST.md](TRUST.md).

Never commit `token.json`, `gcp-oauth.keys.json`, or a filled `.env`.
